# Curricula

The learner web app exposes initial curriculum surfaces:

- `/curricula` shows the vault and hidden/system-managed maintenance path.
- `/curricula/new` starts goal-to-draft creation.
- `/curricula/[id]` shows the outline, frontier, and revision inbox shell.

The first UI slice is intentionally contract-shaped. It gives Batch 11 routes a
place to land while backend service deployment and gateway wiring catch up.
